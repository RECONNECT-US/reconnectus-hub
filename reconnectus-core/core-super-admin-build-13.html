Role Enforcement

Apps become protected when they include the shared reconnectus-access-guard.js file. It checks the Firebase login, active Core profile, role and ticked app permissions.
Each app needs the guard line added once. Future role and permission changes are then read directly from Firebase.

Scan Installed Apps

Core checks the exact top-level folders currently used in your live GitHub repository. When it finds an index.html, it creates or updates that section in Firebase automatically. Some folders are hubs containing several apps, so those individual sub-apps will be scanned later.
