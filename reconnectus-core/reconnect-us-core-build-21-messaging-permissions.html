Role Enforcement

Apps become protected when they include the shared reconnectus-access-guard.js file. It checks the Firebase login, active Core profile, role and ticked app permissions.
App links repaired: Core now opens apps from their live GitHub folder instead of relying on older addresses saved in Firebase.
Each app needs the guard line added once. Access must pass both checks: the user's role must be high enough and the app must be ticked in their profile. Future role and permission changes are then read directly from Firebase.
